# Security Policy

## Supported Versions

Only the latest published release of Glintcast (`0.3.x`) receives security updates.

## Reporting a Vulnerability

If you discover a security or privacy issue in Glintcast:

- Open a report at https://github.com/descentiles/glintcast/issues (or email `descentiles@gmail.com` for sensitive issues).
- Include the Glintcast version, browser version, and steps to reproduce.

Glintcast stores all data locally inside your browser profile and operates no backend servers.
