# Contributing to Glintcast

Thank you for helping make Glintcast calmer, faster, and more reliable on Twitch.

Glintcast's source code is closed and proprietary (see [LICENSE](./LICENSE)), so we do not accept code pull requests on GitHub. The best ways to help are bug reports, Twitch layout-change alerts, accessibility feedback, and focused feature ideas.

## Reporting a Bug or Twitch Change

Twitch updates its layout often. If something looks off or stops working, open an issue at https://github.com/descentiles/glintcast/issues and include:

1. **Glintcast edition and version** (Store or Direct, e.g. `0.3.0`).
2. **Browser** (Chrome, Brave, Edge, Arc, or Opera).
3. **What happened** vs. what you expected.
4. **Other Twitch extensions** you run (FFZ, BTTV, 7TV, etc.).
5. **Screenshot** (if it is a visual or layout issue).

## Suggesting a Feature

Before opening a feature request, check whether it fits Glintcast's design bar:

- Matches Twitch's native controls in both dark and light modes.
- Keeps the interface calm, readable, and clutter-free.
- Works locally in your browser without external servers or tracking.

Describe the problem you are trying to solve in plain language rather than a long list of settings.

## Accessibility & Readability Feedback

We care deeply about comfortable reading, clear contrast, keyboard navigation, and neurodivergent-friendly controls and documentation. If any control, color, or docs page feels overwhelming or hard to read, please open an issue.

## Community Standards

Be kind, concise, and constructive. Harassment, spam, or off-topic self-promotion will be removed.
