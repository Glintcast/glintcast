# Glintcast

Themes, layout modes, and playback controls for Twitch on Chromium browsers (Chrome, Brave, Edge, Arc, Vivaldi, Opera).

- **Documentation:** https://glintcast.mintlify.app
- **Downloads:** [Releases](https://github.com/descentiles/glintcast/releases)
- **Privacy Policy:** [PRIVACY.md](./PRIVACY.md) · https://glintcast.mintlify.app/privacy
- **Bug Reports & Feature Requests:** [Issues](https://github.com/descentiles/glintcast/issues)

## Install (Direct Release)

1. Download `glintcast-direct-v0.3.0.zip` from [Releases](https://github.com/descentiles/glintcast/releases/latest) and extract it to a permanent folder.
2. Open `chrome://extensions` (or `brave://extensions` / `edge://extensions`).
3. Enable **Developer mode**, click **Load unpacked**, and select the extracted folder.
4. Refresh Twitch and click the glint icon in Twitch’s top bar.

See the full [Install Guide](https://glintcast.mintlify.app/install) for Store vs. Direct edition details.

Glintcast is independent and is not affiliated with Twitch.
